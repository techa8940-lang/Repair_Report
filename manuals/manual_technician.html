อุทยานวิทยาศาสตร์ มหาวิทยาลัยนเรศวร (NU SEED AMC Repair)

Technician Manual
1 บทบาทและหน้าที่ของช่างซ่อมบำรุง (Technician Role Overview)
🔧 หน้าที่หลักของช่างในระบบ AMC Repair

ช่างเทคนิคมีบทบาทสำคัญในการดูแลรักษาอาคารสถานที่และระบบสาธารณูปโภค โดยระบบนี้ออกแบบมาเพื่อช่วยให้ช่างทำงานได้อย่างมีประสิทธิภาพ:

  • รับแจ้งเตือนงานทันทีผ่าน LINE: ไม่พลาดทุกงานซ่อมที่ได้รับมอบหมาย ทราบสถานที่และอาการเสียทันที
  • จัดการใบงานผ่านมือถือ: ตรวจสอบรายละเอียด ถ่ายรูปผลงานก่อน-หลัง และกดอัปเดตสถานะได้หน้างานจริง
  • เบิกใช้อะไหล่สะดวก: บันทึกตัดสต็อกอะไหล่ที่ใช้จริงได้อย่างแม่นยำ
2 การผูก LINE User ID เพื่อรับการแจ้งเตือนงานซ่อม (สำคัญที่สุด ⭐)
⚡ ทำไมช่างทุกคนต้องผูก LINE User ID?

เมื่อผู้ดูแลระบบมอบหมายงานซ่อม ระบบจะส่งข้อความแจ้งเตือนเข้าแอป LINE บนมือถือของช่างโดยอัตโนมัติทันที พร้อมปุ่มกดเปิดดูงาน หากไม่ได้ผูกรหัสนี้ ช่างจะไม่ได้รับการแจ้งเตือนงานใหม่ทาง LINE

📱 3 ขั้นตอนง่ายๆ ในการรับรหัส LINE User ID และเชื่อมต่อเข้าระบบ
  1. เพิ่มเพื่อนกับ LINE Official Account ของระบบ: สแกน QR Code หรือเพิ่มเพื่อนกับบอทแจ้งซ่อม NU SEED
  2. ทักทายบอทเพื่อรับรหัส: เปิดแชทแล้วพิมพ์คำว่า id หรือส่งข้อความใดๆ บอทจะตอบกลับเป็นรหัส User ID ประจำตัวของคุณทันที (รหัสขึ้นต้นด้วยตัว U เช่น U89a0b1c2d3e4f5...)
  3. บันทึกรหัสลงในระบบ:
    • เข้าสู่ระบบ -> ไปที่เมนู "ข้อมูลส่วนตัว" ด้านบนขวา
    • วางรหัสที่ได้ลงในช่อง "🟢 LINE User ID สำหรับรับแจ้งเตือน"
    • กดปุ่ม "บันทึกข้อมูลส่วนตัว" เพื่อยืนยัน (หรือแจ้งแอดมินให้ช่วยบันทึกให้)
🔔 การทดสอบการแจ้งเตือน

หลังจากบันทึกแล้ว ในหน้าจัดการข้อมูลส่วนตัวสามารถกดปุ่ม "🔔 ทดสอบส่ง LINE" เพื่อยืนยันว่าระบบสามารถส่งข้อความเข้ามือถือของคุณได้ถูกต้องเรียบร้อย

ระบบแจ้งการซ่อมบำรุง อุทยานวิทยาศาสตร์ มหาวิทยาลัยนเรศวร (NU SEED) หน้า 1 / 3 • คู่มือช่างซ่อมบำรุง

3 ขั้นตอนการปฏิบัติงานซ่อมบำรุง (4 ขั้นตอนหลัก)
📲 แดชบอร์ดโต๊ะทำงานของช่าง (Technician Workbench)

เมื่อเข้าสู่ระบบด้วยบัญชีช่าง ระบบจะนำเข้าสู่หน้าโต๊ะทำงานช่างทันที แสดงรายการงานทั้งหมดที่ได้รับมอบหมาย โดยแบ่งเป็น 4 ขั้นตอน:

ขั้นตอน 1

ตรวจสอบงานที่ได้รับ

ตรวจดูอาคาร ห้อง อาการเสีย ความเร่งด่วน และรูปถ่ายที่ผู้แจ้งแนบมา

ขั้นตอน 2

กดรับงานซ่อม

กดปุ่ม "รับงาน / กำลังดำเนินการ" เพื่อแจ้งผู้แจ้งและแอดมินว่าเริ่มเข้าทำ

ขั้นตอน 3

ลงมือซ่อมและถ่ายรูป

เข้าแก้ไขปัญหาตามมาตรฐานความปลอดภัย และถ่ายภาพผลงานหลังทำเสร็จ

ขั้นตอน 4

บันทึกผลและปิดงาน

ระบุสาเหตุ บันทึกอะไหล่ที่ใช้ และกดปุ่ม "เสร็จสิ้นงานซ่อม"

📝 รายละเอียดการบันทึกผลการซ่อม (Work Notes & Evidence)

เมื่อดำเนินการซ่อมเสร็จสิ้น ให้กดที่คำร้องและกรอกข้อมูลในกล่อง "บันทึกผลการปฏิบัติงาน":

  • สาเหตุของปัญหา (Root Cause): ระบุสาเหตุที่แท้จริง เช่น สายไฟหลวม, สวิตช์หมดอายุการใช้งาน, ท่ออุดตันจากเศษวัสดุ
  • วิธีการแก้ไข (Action Taken): อธิบายสิ่งที่ได้ทำ เช่น เดินสายไฟใหม่, เปลี่ยนลูกลอยชักโครก, ล้างแผงคอยล์เย็น
  • แนบภาพถ่ายหลังซ่อม (After Photo): ควรถ่ายภาพอุปกรณ์หลังซ่อมเสร็จเพื่อเป็นหลักฐานยืนยันความเรียบร้อย
✅ การปิดงาน (Status Transition to Done)

เมื่อตรวจสอบความเรียบร้อยและทดสอบการทำงานแล้ว ให้เลือกเปลี่ยนสถานะเป็น "🟢 เสร็จสิ้น (Resolved)" ระบบจะบันทึกเวลาที่ซ่อมเสร็จ และส่งการแจ้งเตือนไปยังผู้แจ้งซ่อมว่างานเสร็จสิ้นเรียบร้อย

⚠️ กรณียังไม่สามารถซ่อมให้เสร็จได้ในทันที
  • รออะไหล่: หากต้องรอจัดซื้ออะไหล่ ให้ระบุในหมายเหตุว่า "รออะไหล่..." เพื่อให้ผู้แจ้งและแอดมินรับทราบ
  • ประสานผู้รับเหมาภายนอก: หากเป็นงานขนาดใหญ่ ให้รายงานต่อผู้ดูแลระบบเพื่อทำเรื่องส่งต่อ

4 การเบิกใช้อะไหล่และอุปกรณ์ (Parts Requisition)
📦 ขั้นตอนการบันทึกเบิกใช้อะไหล่ในใบงาน
  1. ในหน้าต่างรายละเอียดงานซ่อม ให้เลื่อนลงมาที่ส่วน "เบิกใช้อะไหล่ / อุปกรณ์"
  2. คลิกเลือกรายการอะไหล่จากคลังสต็อก (เช่น หลอดไฟ LED T8 18W, ท่อ PVC 1/2 นิ้ว, เทปพันสายไฟ)
  3. ระบุจำนวนชิ้นที่เบิกใช้จริง แล้วกดปุ่ม "บันทึกการเบิกอะไหล่"
  4. ระบบจะตัดสต็อกคงเหลือในคลังพัสดุอัตโนมัติ และแสดงรายการอะไหล่ที่ใช้แนบไว้ในรายงานของคำร้องนั้น

6 มาตรฐานความปลอดภัยในการปฏิบัติงาน (Safety First ⚠️)
🚨 กฎเหล็กด้านความปลอดภัยที่ต้องปฏิบัติตามอย่างเคร่งครัด
  • ตัดระบบพลังงานก่อนเริ่มซ่อม (LOTO): ปลดคัตเอาต์/เบรกเกอร์ไฟฟ้า หรือปิดวาล์วน้ำหลักทุกครั้ง และแขวนป้ายเตือน
  • สวมอุปกรณ์คุ้มครองความปลอดภัย (PPE): สวมถุงมือฉนวน, แว่นตานิรภัย, รองเท้าหัวเหล็ก/กันลื่นตามประเภทงาน
  • การทำงานบนที่สูง: ใช้บันไดที่ได้มาตรฐาน มีผู้ช่วยจับฐาน และสวมเข็มขัดนิรภัยเมื่อทำงานสูงเกิน 2 เมตร
  • ตรวจสอบความเรียบร้อย: ทดสอบระบบไฟฟ้า/ประปาหลังซ่อมเสร็จ และทำความสะอาดเก็บกวาดเศษวัสดุก่อนส่งมอบงาน
